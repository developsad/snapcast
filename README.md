# React Vite Project

This is a React project built with Vite.

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## Features

- React 18
- Vite for fast development and building
- Hot Module Replacement (HMR)
